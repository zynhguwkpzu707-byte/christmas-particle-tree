# 回忆照片

这里用来放会出现在金色条状彩带**正面**的回忆照片。

## 添加照片

1. 把图片复制到本文件夹，例如 `photos/2024-summer.jpg`。
2. 打开 `photos/memories.js`，在数组中添加一条记录：

```js
window.MEMORY_PHOTOS = [
  { src: 'photos/2024-summer.jpg', caption: '那个夏天' },
  { src: 'photos/first-snow.png' },
];
```

3. 刷新页面，靠近圣诞树让彩带绽放，照片就会显示在金色条带正面。如果照片没有更新，请按 `Ctrl+F5` 强制刷新一次。

## 规则

- 最多读取 16 张照片。
- 支持 `.jpg`、`.png`、`.webp`。
- 建议使用 **4:5 或 3:4 的竖图**，分辨率至少 800px；横图会自动居中裁剪。
- `caption` 可选，会显示在照片底部的金色小条上，最多 28 个字符。
- 照片只出现在彩带的**单面**；翻到背面时会看到纯金色条带。
- 照片文件只在本地加载，不会上传。
